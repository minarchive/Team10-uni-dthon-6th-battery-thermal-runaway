# 규칙 적용 프로토콜 (결과를 보기 전에 고정)

목적: 데이터에서 발견한 규칙을 하나씩 모델에 적용하되, Train 에 과적합한 규칙이 채택되지 않도록 평가·채택 기준을 **미리** 고정한다.
채택 판정은 `src/protocol_runner.py` 가 자동으로 수행한다 (사람이 결과를 보고 기준을 바꾸지 않는다).

## 1. 고정 사항 (실험 중 변경 금지)
| 항목 | 값 |
|---|---|
| 데이터 | Train+Validation 97개 실험 (Test 는 최종 예측 외에 사용 안 함) |
| 평가 | 실험 단위 GroupKFold(5) × 3 반복 (반복마다 실험을 다시 섞음, 모든 후보가 같은 분할 사용) |
| 모델 | LightGBM 다중분류, lr 0.1, 150 트리, leaves 31, min_child 60, feature_fraction 0.4, class_weight=balanced. **후보마다 튜닝하지 않는다** |
| 평가 행 (Test 와 동일하게) | 실험당 **500행 상한**: 500행을 넘는 실험은 무작위로 500행(첫 행 포함)만 남기고 **그 행들로 피처를 다시 계산**해 채점. 학습은 전체 길이 행 |
| 주 지표 | 위 Test-like 행의 풀링 OOF Macro-F1 (인과 cummax 후처리 적용), 3 반복 평균 |
| 보조 지표 | raw F1, 실험별 정확도, 공식 Validation 19개 실험만의 F1(Test-like), 라벨별 F1, 참고용 전체 길이 풀링 F1 |

> **변경 이력 (결과를 읽기 전에 수정)**: 최초 버전은 전체 길이 행으로 풀링 채점했다. Test 11개 중 2개가 6,000초 안팎 실험을 정확히 500행으로 줄인 것이고(나머지 9개는 원본 5초, 최대 325행),
> Train+Val 은 25/97개 실험이 500행을 넘어 전체 프레임의 56%를 차지하므로, 전체 길이 풀링은 Test 와 비중이 다르다. 그래서 평가를 Test-like 로 교체하고 처음부터 다시 실행했다. 채택 기준(2절)과 후보(3절)는 바꾸지 않았다.
| 시드 | 분할 0,1,2 / 모델 42 |

## 2. 채택 기준 (모두 만족해야 채택, 하나라도 실패하면 기각)
1. 주 지표 개선 Δ ≥ **+0.003**
2. 실험별 정확도 차이(후보−기준)의 실험 단위 부트스트랩 95% 신뢰구간 **하한 > 0** (3 반복 평균, 2000회)
3. 3 반복 중 **2회 이상** 주 지표가 개선
4. 공식 Validation 19개 실험 부분 점수가 **−0.01 보다 더 나빠지지 않음**
5. 규칙이 **자유 파라미터 없이** 정의되거나(고정 상수/물리적 의미) 파라미터를 학습 fold 안에서만 정함
6. 모든 새 피처는 **인과성 검사 통과** (실험을 앞 60%에서 잘라 계산해도 앞부분 값이 동일해야 함)

동률/애매하면 더 단순한 쪽(기준)을 유지한다. 채택은 누적(그리디): 채택된 규칙은 이후 후보의 기준에 포함된다.
후보는 아래 7개로 **고정**하며, 결과를 본 뒤 후보를 추가하지 않는다 (다중 비교로 인한 우연 채택 방지).

## 3. 후보 규칙 (순서 고정)
| ID | 규칙 | 근거 (EDA) | 구현 |
|---|---|---|---|
| E1 | **L2 시계**: T1 ≥ 45℃ 도달 이후 경과시간, 도달 시각, 도달까지 평균 가열속도 | L1→L2 는 97/97 실험에서 T1=45.0℃ 에서 시작 (규칙), L2 이후 시간이 L3 진입과 연관 | 피처 추가 (5개) |
| E2 | **레짐 간접 피처**: 45℃ 도달 이후 T1/T2/thermal 평균 상승속도, 도달 시점 T1−T2 | L3 시작이 빠른/느린 두 레짐으로 갈림 → 레짐을 직접 못 맞히므로 속도로 간접 표현 | 피처 추가 |
| E3 | **방식별 트리거 신호**: tr_method=1 → T1, tr_method=2 → thermal_t 를 하나의 'trigger' 신호로 보고 cummax/상승량/기울기 | L2 vs L3 단일 특징 stump: 가열은 T1(0.80), 과충전은 thermal_t(0.86) | 피처 추가 |
| E4 | **실험 균형 가중**: 프레임 가중치에 1/√(실험 프레임 수) 곱함 | 긴 실험(1,500 프레임)이 학습을 지배, 오류가 소수 실험에 집중 | 가중치 |
| E5 | **조건 크기 제거**: `bat_cc`, `soc_status` 제외 (`bat_class`, `tr_method` 유지) | 실험 11개뿐인 Test 에서 조건 조합에 과의존 방지 | 컬럼 제거 |
| E6 | **순서형 + 단조 제약**: P(y≥k) k=2..6 이진 모델, 온도 cummax 계열 피처에 단조 증가 제약 | 라벨이 진행 단계이므로 단조 관계가 물리적으로 타당, 과적합 억제 | 모델 구조 |
| E7 | **강한 정규화**: leaves 15, min_child 200, lambda_l2 20 | 실험 단위 일반화 | 하이퍼파라미터(사전 고정 1회) |

이미 결과가 있는 항목(참고, 이 프로토콜 밖): 이미지 전 프레임 투입·게이팅(이득 없음), HMM 필터(이득 없음), 클리닝/사건 피처(실험 단위 검정 유의하지 않음).
이미지 크기(size_*)는 항상 모델 입력에서 제외한다.

## 4. 과적합 점검 (최종)
- 채택된 최종 구성: Train 만 학습 → Train 점수 vs 공식 Validation 점수의 격차 기록.
- Test 입력 피처 분포가 Train+Val 범위를 벗어나는지(범위 밖 비율) 기록.

## 5. 라운드 2 후보 (라운드 1 결과 E1~E7 을 읽기 **전에** 등록, EDA v2 근거)
채택 기준·평가는 1~2절과 동일. 라운드 1 종료 후 그 시점의 채택 구성을 기준으로 아래 순서대로 그리디 평가한다. 후보는 이 5개로 고정.
| ID | 규칙 | 근거 (EDA v2) | 구현 |
|---|---|---|---|
| E8 | **L1 규칙 + 조건부 모델**: 예측 L1 ⇔ T1 cummax<45℃ (규칙), 그 외 프레임만으로 L2~L6 모델 학습·예측 | L1→L2 는 97/97 규칙, 변위 0. L1 프레임(43%)을 학습에서 빼면 어려운 경계에 용량 집중 | 학습 행 필터 + 추론 시 규칙 |
| E9 | **L2→L3 전문가 캐스케이드**: ① L2 vs ≥L3 이진 모델(트리거 신호·45℃ 시계 피처) ② L3~L6 모델 | L2→L3 만 ±6프레임 이내 37%(나머지 경계 81~97%), 오류의 대부분이 이 경계 | 모델 구조 (확률 결합: P(≥L3)·P(k│≥L3)) |
| E10 | **Test 모사 학습**: 학습 행에 실험당 500행 상한 가중(w=min(1,500/n))과 500행 무작위 재표집 사본 추가 | Test 2/11 실험이 500행 재표집(간격 혼재), 평가 가중과 학습 가중 일치 | 가중치 + 증강 |
| E11 | **경계 집중 가중**: 정답 경계 ±24프레임 안 학습 프레임에 가중 ×2 | 오류의 58%가 경계 ±24프레임 안 | 가중치 |
| E12 | **이미지 상대 변화(L2→L3 전문가 전용)**: 실험 첫 프레임 대비 body_frac, heat_p90 변화 | 실험 내 AUC 0.92(전체 0.56~0.73), 단 경계 ±30초 AUC 는 센서가 압도 | E9 의 ① 모델에만 피처 추가 (기대치 낮음, 마지막) |

주의: E12 는 이미지 크기 지름길을 피하려 크기 피처를 쓰지 않고, 첫 프레임 대비 상대량만 사용한다.

## 6. 라운드 2 재등록 — 이벤트 상태기계 중심 (5절의 E8~E12 를 대체)
> **작성 경위 (사실 그대로)**: 이 절은 라운드 1(E1~E7, 전부 기각) 결과를 **읽은 뒤**에 작성했다. 5절 후보를 실행하기 전에, 데이터 출처(AI Hub)의 라벨 포맷에
> '이상 이벤트 플래그 7개'(온도증가, 압력 연속 상승, 전압 1·2차 급락, 전압 크기, 온도증가2, 온도 크기)가 있음을 확인했고, 센서에서 이벤트를 검출해 단계 시작과 비교했다(EDA).
> 결과: L2 시작 = T1≥45℃ (97/97), L4 시작 = 전압이 시작값의 70% 아래로 처음 떨어지는 순간(±2프레임 91%, 임계 0.6~0.9 에서 거의 동일), L5/L6 부분 일치, L3 는 압력·가스·온도 변화율·T1 임계 어느 것으로도 설명 안 됨(최대 25%).
> **한계**: 이 규칙들은 97개 실험 전체에서 발견했으므로(교차검증 밖), 아래 후보의 점수 비교는 규칙 후보에 유리하게 편향될 수 있다. 완화책은 (a) 상수가 2개뿐이고(45℃, 0.7) 민감도가 낮으며 (b) 채택 기준을 라운드 1과 동일하게 유지하는 것이다. 최종 확인은 Test 점수뿐이다.

채택 기준(2절), 평가(1절)는 그대로. 후보는 아래 5개로 **고정**, 순서 고정, 그리디(누적). 구현은 `src/rules.py`, `src/protocol_runner.py --round 2`.
| ID | 규칙 | 근거 | 구현 |
|---|---|---|---|
| F1 | **가스 피처 제거**: 가스 10종과 그 파생(인과 윈도 포함), `gas_sum_log` 제외 | L2→L3 경계에서 가스 AUC≈0.5(정보 없음), 팀 측정에서 가스 피처 제거가 이득 | 컬럼 제거 |
| F2 | **규칙 제약 디코딩**(후처리): T1 cummax<45℃ → L1 고정, 도달 후 ≥L2; 전압 급락 사건 발생 전 → ≤L3, 발생 후 → ≥L4 (그 뒤 cummax) | L2, L4 경계가 규칙으로 확인됨 | 후처리 |
| F3 | **사건 시계 피처**: 전압 급락 이후 경과시간, V/V0 누적 최솟값, V/V0<0.3 이후 경과, T1≥500℃ 이후 경과, T1 1프레임 +20℃ 이후 경과, T2≥400℃ 이후 경과 | L4~L6 시작이 해당 사건과 부분/강하게 일치 | 피처 추가 (인과성 검사 필수) |
| F4 | **상태별 전문가 모델**: 규칙 상태(① T1<45 ② 도달 후 급락 전 ③ 급락 후)별로 모델을 따로 학습·예측 | 상태기계: 구간마다 구분 문제가 다름(②는 L2 vs L3, ③은 L4/L5/L6) | 모델 구조 (상태는 라벨이 아닌 규칙으로 정의) |
| F5 | **경계 집중 가중**: 정답 경계 ±24프레임 학습 프레임 가중 ×2 | 오류 58%가 경계 ±24프레임 안 | 가중치 |

L3 트리거는 아직 정의를 찾지 못했으므로 후보에서 제외한다(데이터 설명서의 단계 정의를 확인하면 별도 등록).

> **상태 (2026-11-15)**: 라운드 2 는 실행 중 사용자 결정으로 **중단**했고 결과가 없다(구현은 `src/rules.py`, `src/protocol_runner.py --round 2` 에 남아 있어 재개 가능).
> 팀원의 외부 측정(센서 LightGBM OOF 기준 0.9051, 재현 안 함)에서 규칙 상태 게이팅(F2/F4 와 같은 계열)은 이득이 없었다: 전압 급락 트리거 V/V0≤0.8 → −0.0012(0/5 fold), ≤0.9 → +0.0001(1/5),
> ≤0.95 → −0.0018, '한 칸 하락 ≥0.1' → −0.0409(위반 2.5%). 규칙 위반 프레임은 0.4~0.6%. 이 증거에 따라 **F2, F4 는 우선순위를 낮추고, 규칙은 모델 입력 피처로만 쓴다**(모델이 이미 학습하고 있음).
