**1. 시계열과 이미지는 경계에서 같은 정보를 준다 (이미지의 추가 정보 없음)**
- 경계 ±24프레임에서 '경계 후인가'를 맞추는 OOF AUC: 센서 1.000 / 0.861 / 0.982 / 0.972 / 0.975, 이미지 단독 0.847 / 0.739 / 0.845 / 0.924 / 0.896 (L1→L2 … L5→L6).
- 센서+이미지 − 센서 차이의 95% 신뢰구간(실험 단위 부트스트랩)이 **5개 경계 모두 0을 포함**한다(L2→L3: −0.007 [−0.019, +0.004]). 이미지는 어느 경계에서도 센서에 정보를 더하지 못한다. 이미지가 가장 낮은 경계는 L2→L3(0.739)이고 센서도 거기가 가장 약하다(0.861).
- 따라서 '센서 모델 따로, 이미지 모델 따로'의 확률 결합은 근거가 없다. 현재 표현(색 통계)의 결론이며, L2→L3 전용 이미지 표현은 별도 검증 대상.

**2. 경계마다 성격이 다르다**
- L1→L2: T1=45℃ 규칙(97/97), 변위 0. L3→L4 / L4→L5 / L5→L6: 센서가 ±6프레임(30초) 이내로 맞춘 실험 비율 97% / 90% / 81%.
- **L2→L3만 불안정**: ±6프레임 이내 37%, ±24프레임 이내 75%, 100프레임 넘게 어긋난 실험 3%.
- 사건 정렬(T1=45℃ 도달=0) 후 L3 시작 중앙값: prism|tr1 62초, cyl|tr1 185초, pouch|tr1 168초, pouch|tr2 235초, prism|tr2 355초 → 같은 사건 시계에서도 그룹마다 지연이 크게 다르다.

**3. 오류의 구조 (센서 OOF, cummax)**
- 오류 프레임의 58%는 정답 경계 ±24프레임(2분) 안, 24%는 경계에서 60프레임(5분) 넘게 떨어져 있다(구간 전체가 틀리는 체계적 오분류, 예: 느린 가열 실험의 L5).

**4. 천장 추정 (경계 지터 곡선)**
- 모든 경계를 U(−k,k) 프레임 어긋나게 하면 F1: k=5 → 0.945, k=8 → 0.917, k=12 → 0.883, k=18 → 0.839.
- 우리 OOF 0.865 ≈ k≈14(±72초), 참고 최고 점수 0.9447 ≈ k≈5(±25초). 우리는 L1→L2·L3→L4·L4→L5 가 이미 거의 정확하므로 **격차의 대부분은 L2→L3 경계와 구간 단위 오분류**에서 나온다. (가정: 모든 경계에 같은 지터, 참고 점수는 다른 분할 → 대략적 지표)

**5. 평가 설계에 대한 발견**
- Test 11개 중 2개는 6,000초 안팎 실험을 정확히 500행으로 줄인 것(간격 10/15초 혼재)이고 나머지 9개는 원본 5초(최대 325행). Train+Val 은 25/97개 실험이 500행 초과(전체 프레임의 56%).
- 전체 길이로 풀링한 OOF 는 긴 실험이 지배하므로 Test 와 가중이 다르다 → 평가를 '실험당 500행 상한(무작위, 첫 행 포함) + 피처 재계산'으로 맞춘다(PROTOCOL.md 변경 이력).

**7. 팀 분석과의 교차 확인 (5절)**
- 두 OOF 에서 같은 패턴이 확인되면 모델 설정과 무관한 구조적 특성이다: L2 가 가장 약한 단계, 파우치가 가장 약한 형태(L4/L5 학습 행이 적음), 오류가 소수 실험에 집중.

- 실험·조건 균형 가중과 정규화(E4, E5, E7)는 이 관점에서 이미 라운드 1 후보에 들어 있다.
