이미지 가공

열화상 이미지를 온도 인덱스로 바꾸는 과정

가공 방식이 달라지면 같은 이미지에서 뽑히는 정보가 달라집니다. 아래 실제 프레임 그림은 같은 실험의 L2와 L4 프레임에 각 처리 단계를 적용한 모습이고, 그 아래 도식은 비교 중인 처리 방식입니다.

팔레트 → 상대 온도 인덱스(0~1)

0 (자홍, 차가움)0.5 (초록)1 (흰색, 뜨거움)

절대 온도가 아닌 RGB 근사입니다. 카메라 구도와 이미지 크기가 13종으로 달라서 인덱스의 절대값은 실험 간에 비교하기 어렵습니다.

비교 중인 가공 방식

  1. 흑백 통계 (공식 베이스라인): L 채널의 평균, 표준편차, 최댓값, p95, p99, 고온 비율
  2. 온도 인덱스 통계: hue를 0~1로 변환한 뒤 백분위수·히스토그램·가장자리 밀도
  3. 배경 마스크: 인덱스 0.12 이하(자홍 배경)를 제외한 가열 영역 면적과 상위 10% 온도
  4. 첫 프레임 대비 상대화: 같은 실험의 첫 프레임 값을 빼서 구도 차이를 제거(과거만 사용)
  5. 64×64 리사이즈: 해상도·종횡비 차이가 통계에 미치는 영향 확인

경계 지터와 팀 분석

범위와 한계: 점수는 Train+Validation 97개 실험의 교차검증이며 Test 점수가 아닙니다. 스케일링·상대화 비교는 전체 길이 풀링에서 다른 설정(150 트리, 부표본 학습)으로 한 것이라 프로토콜의 0.8914와 직접 비교하지 않습니다. 후보 규칙의 기각은 "이 평가와 이 모델에서 개선이 확인되지 않았다"는 뜻이지 해롭다는 뜻이 아닙니다. 이 페이지에는 대회 데이터의 실제 열화상 프레임과 센서 시계열이 들어 있습니다(sample_id와 실험 id는 표시하지 않음). 비공개 링크지만, 공유 범위를 정할 때 대회의 데이터 취급 규정을 확인해 주세요. 팀원 분석(L2·L3 열화상 비교, 단계별·클래스별 집계)은 외부 입력으로 표시했고 재현하지 않았습니다.
