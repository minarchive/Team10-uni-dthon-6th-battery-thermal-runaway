**1. 데이터 특성 → 설계**
- 라벨은 97개 실험 모두 단조 비감소, 단계 시작 시각 편차가 큼 → 인과 후처리(cummax)는 유효하지만 `relative_time_s` 단독 신호는 약함(S6 +time 이 오르지 않음).
- 이미지 크기 → `bat_class` 규칙 정확도 100% = 완전한 지름길. 그러나 크기만 쓴 B0 는 Val F1 0.196, 조건만 쓴 B0c 는 0.263 으로 낮고, 크기 추가(S5)는 이득이 없었다. 지름길 위험은 실재하지만 이 모델에서는 활용되지 않음.
- 센서 값 자체의 train/test 분포 이동은 거의 없음(adversarial AUC ≈ 0.5). Test 의 차이는 실험 구성과 간격(11개 중 2개 실험이 10/15초).

**2. 모델 선택 (Validation Macro-F1)**
- 센서 원본 0.723 → +인과 시계열 0.780 → +이미지 원본 통계 0.792(선택 S3) → 이미지 시계열 추가는 하락(0.774). 이미지만 쓰면 0.649.
- class_weight=balanced + 간격 증강, 인과 cummax 후처리를 적용한 최종 Validation F1 = 0.803.
- 약점은 L5(recall 0.46, 대부분 L4로 예측)와 그로 인한 L4 precision(0.35). Validation 은 L5 비중이 11%(Train 5.7%)라 점수를 크게 깎는다.

**3. 이미지 게이팅 (Train+Val 97개 실험 OOF 로 규칙 선택)**
- 센서 단독 OOF F1 0.860 → 최적 게이트 0.866(+0.006, 규칙: 센서 예측 {2,3,4} 전체에 α=0.5). 센서 단독 + cummax 는 이미 0.865 이므로 **게이팅의 순이득은 사실상 0.001 수준으로 노이즈 범위**.
- "확신도가 낮은 프레임만" 보정하는 가설(τ<1)은 OOF 에서 이득이 없었다(τ 선택이 1.01=항상 적용).
- L2→L3 구제 208프레임 대비 L2 악화 214프레임 등, 구제와 악화가 거의 상쇄. L5 는 이미지가 구제한 프레임 0 → 선행 분석(이미지는 L5 를 못 돕는다)과 일치.
- 이미지 순서형 AUC 는 y≥3 0.981, y≥4 0.960 으로 센서(0.991, 0.998)보다 낮아 보완 여지가 작다. 학습된 인코더(DINOv2 등) 확률로 교체하면 달라질 수 있음.
